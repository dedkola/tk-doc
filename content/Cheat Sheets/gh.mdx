## Installation & Setup

### Install GitHub CLI

```bash
# macOS
brew install gh

# Windows (winget)
winget install --id GitHub.cli

# Windows (Chocolatey)
choco install gh

# Ubuntu / Debian
sudo mkdir -p -m 755 /etc/apt/keyrings \
  && wget -qO- https://cli.github.com/packages/githubcli-archive-keyring.gpg | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
  && sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
  && echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
  && sudo apt update \
  && sudo apt install gh -y

# Fedora
sudo dnf install gh

# Arch Linux
sudo pacman -S github-cli

# Verify installation
gh --version
```

### Shell Autocomplete

```bash
# Bash
gh completion -s bash | sudo tee /etc/bash_completion.d/gh_completion > /dev/null

# Zsh
gh completion -s zsh > ~/.zfunc/_gh

# Fish
gh completion -s fish > ~/.config/fish/completions/gh.fish
```

### Update GitHub CLI

```bash
gh extension upgrade gh-copilot   # update a single extension
gh extension upgrade --all        # update all extensions
brew upgrade gh                   # macOS with Homebrew
```

## Authentication

### Login & Logout

```bash
gh auth login                     # interactive login (HTTPS or SSH)
gh auth login --web               # login via browser
gh auth login --with-token < token.txt   # login with personal access token
gh auth login --hostname github.example.com  # GitHub Enterprise Server
gh auth status                    # show current authentication status
gh auth logout                    # log out of GitHub
gh auth refresh                   # refresh stored credentials
gh auth refresh --scopes write:packages,delete:packages  # add extra scopes
```

### Token Scopes Reference

| Scope              | Purpose                              |
| ------------------ | ------------------------------------ |
| `repo`             | Full control of private repositories |
| `repo:invite`      | Access repository invitations        |
| `public_repo`      | Access public repositories           |
| `read:org`         | Read organization membership         |
| `write:org`        | Manage organization membership       |
| `read:user`        | Read user profile data               |
| `gist`             | Create and manage gists              |
| `workflow`         | Manage GitHub Actions workflows      |
| `delete_repo`      | Delete repositories                  |
| `write:packages`   | Upload packages to GitHub Packages   |
| `admin:public_key` | Manage public SSH keys               |

## Configuration

### View & Set Configuration

```bash
gh config list                    # show all config values
gh config get editor              # get a specific config value
gh config set editor "code --wait"  # set default editor
gh config set git_protocol ssh    # use SSH for git operations
gh config set git_protocol https  # use HTTPS for git operations
gh config set prompt disabled     # disable interactive prompts
```

### Common Configuration Options

| Option         | Values                | Description                             |
| -------------- | --------------------- | --------------------------------------- |
| `git_protocol` | `https`, `ssh`        | Protocol used for git operations        |
| `editor`       | editor command        | Default editor for interactive commands |
| `prompt`       | `enabled`, `disabled` | Enable/disable interactive prompts      |
| `pager`        | pager command         | Program used to paginate output         |

## Repositories

### Create & Clone

```bash
gh repo create my-repo            # create a new public repo
gh repo create my-repo --private  # create a private repo
gh repo create my-repo --internal # create an internal repo (Enterprise)
gh repo create my-org/my-repo --private --clone  # create in org and clone
gh repo create --source=. --public --push        # push current directory

gh repo clone owner/repo          # clone a repository
gh repo clone owner/repo my-dir   # clone into custom directory
gh repo fork owner/repo           # fork a repository
gh repo fork owner/repo --clone   # fork and clone locally
gh repo fork owner/repo --org my-org  # fork into an organization
```

### View & Manage

```bash
gh repo view                      # view current repository info
gh repo view owner/repo           # view specific repository
gh repo view --web                # open repository in browser
gh repo view --branch main        # view specific branch

gh repo list                      # list your repositories
gh repo list owner --limit 50     # list repositories for a user/org
gh repo list --source             # list only source repos (no forks)
gh repo list --fork               # list only forks

gh repo delete owner/repo         # delete a repository
gh repo archive owner/repo        # archive a repository
gh repo unarchive owner/repo      # unarchive a repository
gh repo rename my-new-name        # rename current repository
gh repo edit --description "New description"  # update repo description
```

### Sync & Remotes

```bash
gh repo set-default owner/repo    # set default repository for current dir
gh repo sync                      # sync current branch with upstream
gh repo sync owner/repo --branch main  # sync specific branch
gh repo sync --force              # force sync (overwrite local changes)
```

## Pull Requests

### Create Pull Requests

```bash
gh pr create                      # create PR interactively
gh pr create --title "Fix login" --body "Closes #123"
gh pr create --fill               # auto-fill title/body from commits
gh pr create --fill-first         # use first commit for title/body
gh pr create --draft              # create as draft PR
gh pr create --web                # open PR creation in browser
gh pr create --base main --head feature-branch
gh pr create --reviewer username1,username2
gh pr create --assignee @me
gh pr create --label bug,critical
gh pr create --project "Q3 Roadmap"
```

### List & View

```bash
gh pr list                        # list open PRs
gh pr list --state all            # list all PRs
gh pr list --state merged         # list merged PRs
gh pr list --state closed         # list closed PRs
gh pr list --author @me           # authored by you
gh pr list --assignee @me         # assigned to you
gh pr list --review-requested @me # requesting your review
gh pr list --label bug            # filter by label
gh pr list --limit 50             # limit results
gh pr list --json number,title,author,state  # JSON output

gh pr view 42                     # view PR details
gh pr view 42 --web               # open PR in browser
gh pr view --comments             # view PR with comments
```

### Checkout & Review

```bash
gh pr checkout 42                 # checkout PR locally
gh pr checkout 42 --branch pr-42  # checkout into named branch
gh pr checkout 42 --recurse-submodules  # also update submodules
gh pr checkout 42 --force         # reset branch and checkout PR

gh pr diff 42                     # view PR diff
gh pr diff 42 --color always      # force color output
gh pr diff 42 --patch             # output in patch format

gh pr review 42 --approve         # approve PR
gh pr review 42 --request-changes -b "Needs tests"
gh pr review 42 --comment -b "Looks good, one question"
gh pr review 42 --body "Approved"  # non-interactive approval
gh pr checks 42                   # view PR check status
```

### Merge & Close

```bash
gh pr merge 42                    # merge PR interactively
gh pr merge 42 --merge            # create a merge commit
gh pr merge 42 --squash           # squash and merge
gh pr merge 42 --rebase           # rebase and merge
gh pr merge 42 --auto             # enable auto-merge
gh pr merge 42 --delete-branch    # delete branch after merging
gh pr merge 42 --admin            # use admin privileges to merge

gh pr close 42                    # close PR without merging
gh pr close 42 --delete-branch    # close and delete branch
gh pr reopen 42                   # reopen closed PR
gh pr ready 42                    # mark draft PR as ready
```

### Update PRs

```bash
gh pr edit 42 --title "New title"
gh pr edit 42 --body "Updated description"
gh pr edit 42 --add-label enhancement
gh pr edit 42 --remove-label bug
gh pr edit 42 --add-assignee username
gh pr edit 42 --add-reviewer username
gh pr comment 42 --body "Great work!"
```

### Create Releases

```bash

gh release create v1.0.0 --notes "Release notes"

gh release create v1.0.0 --target main  # use specific commit/branch
```

### Manage Releases

```bash
gh release list                   # list releases

gh release view v1.0.0 --web      # open release in browser
gh release download v1.0.0        # download all assets
gh release download v1.0.0 --pattern "*.zip"
gh release download v1.0.0 --archive tar.gz
gh release edit v1.0.0 --draft=false  # publish draft
gh release delete v1.0.0          # delete release
gh release upload v1.0.0 asset.zip  # upload asset to existing release
gh release delete-asset v1.0.0 asset.zip  # delete an asset
```

## GitHub Actions Workflows

### List & View

```bash
gh workflow list                  # list workflows
gh workflow list --all            # include disabled workflows
gh workflow view deploy.yml       # view workflow details
gh workflow view deploy.yml --web # open workflow in browser
gh workflow view deploy.yml --yaml  # view workflow YAML
```

### Run & Manage

```bash
gh workflow run deploy.yml        # trigger workflow manually
gh workflow run deploy.yml --ref main
gh workflow run deploy.yml -f env=production -f version=1.2.3
gh workflow run deploy.yml --raw-field config="$(cat config.json)"

gh workflow enable deploy.yml     # enable workflow
gh workflow disable deploy.yml    # disable workflow
gh workflow delete deploy.yml     # delete workflow
```

### Workflow Runs

```bash
gh run list                       # list recent workflow runs
gh run list --workflow deploy.yml # list runs for specific workflow
gh run list --branch main         # filter by branch
gh run list --status failed       # filter by status
gh run list --limit 20

gh run view 1234567890            # view run summary
gh run view 1234567890 --log      # view full logs
gh run view 1234567890 --log-failed  # view only failed job logs
gh run view 1234567890 --web      # open run in browser
gh run view --job 9876543210      # view specific job

gh run watch 1234567890           # watch run in real-time
gh run rerun 1234567890           # rerun failed jobs
gh run rerun --failed             # rerun all failed jobs
gh run cancel 1234567890          # cancel a run
gh run delete 1234567890          # delete a run
gh run download 1234567890        # download artifacts
gh run download 1234567890 --name dist  # download specific artifact
```

## Tips & Best Practices

```bash
# Use --web to open any view in browser when you need the UI
gh pr view 42 --web

# Combine gh with git for powerful workflows
git checkout -b feature && gh pr create --fill

# Auto-fill PRs from conventional commits
gh pr create --fill

# Review PRs from terminal with diffs and comments
gh pr checkout 42 && gh pr diff && gh pr review

# Use jq with --json for scripting
gh pr list --json number,title --jq '.[] | "#\(.number) \(.title)"'

# Set default repo to avoid typing owner/repo repeatedly
cd my-repo && gh repo set-default owner/repo
```
